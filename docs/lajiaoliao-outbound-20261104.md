# 辣椒聊受控发送接入

## 范围

复用当前账号的单读取连接，发送原生 101 文本、102 图片、103 语音、
104 视频、106 单成员提及及 114 本群近期文本引用。私聊仅开放对已认证
自有账号的文本和图片受控测试；文件、账号设置及生产助手执行不随本轮开放。
移动端演示保留为接收证据，不能代替本站发送验收。

## 边界与持久化

`internal/control/chili_message.go` 从本账号七日内密封原消息解析字符串
身份、原生引用标识及私聊目标；浏览器只提交当前作用域中的事件编号或
明确授权的成员。提交前重新检查窗口、预算、账号 epoch、绑定、连接所有者、
当前原生角色及目标。引用和私聊源摘要改变时拒绝提交。

私聊历史只有图片时，允许从`lajiaoliao_content_type`投影及保留的原生消息
重新解析已支持的格式和对端身份；未知内容、其他失败原因、跨账号、过期源
和未认证收件人仍拒绝。群引用始终要求可引用的本群文本，不因这一读取路径
扩大到图片引用。窗口的`account_ids`只含执行者，明确自有收件人的 epoch
单独快照；收件人不会因此获得执行权。

`internal/lajiaoliao/outbound.go` 负责平台原生消息格式；
`internal/gateway/lajiaoliao_media.go` 使用现有连接读写协调与最终提交栅栏。
没有增加连接、worker、自动重发或每群任务。上传和发送分别消耗显式预算。
未知结果只能按原 clientMsgID、发送者、会话、正文摘要和消息类型核对持久回显。

前向迁移 046 增加独立 `lajiaoliao_media_attempts`，不修改旺商聊 nonce 表。
041 是工作区中未交付的旧候选；已记录 041 的环境验证其表存在后跳过建表，
未记录的当前运行环境由 046 创建。既有迁移不改写。

## 界面与验收

消息输入区提供文本、引用及单成员提及模式；候选来自当前授权群，有界读取。
图片、MP3/WAV 语音和带 JPEG 封面的 MP4 使用既有作用域上传组件。
没有受控窗口时只读，关闭或查看不提交。

功能表按本平台实现、指定场景验收和生产准入分别更新。
禁言、解禁及名单回读已有本轮独立通过记录；新发送和头像结果见
`docs/test-report.md`。本站群文本、引用、@、群图片、MP3、MP4、私聊文本
及私聊图片均取得成功回执，并从另一自有账号精确匹配发送消息的原生client
标识、类型、发送者和会话。引用正文与本群选中原文核对，图片、视频及封面
资源另行读取成功。
头像使用本人当前图片规范化重传，最终设置成功且256×256新图实际回显。
这些指定场景证据不等同生产准入；WAV和移动端播放未在本轮验收。

## 上传与资源读取

固定IM对象上传API返回`lj-chat-im-01-hz-acc.lajiaoliao.com`签名PUT地址。
只允许已核验的HTTPS来源；IM票据不转发到对象存储。新对象读取地址可能是
`im-api.lajiaoliao.com/object/*`，返回302到
`lj-chat-im-01.lajiaoliao.com`。读取器仅显式允许这一跳，且重新构造不含
Cookie、token、Authorization的GET；第二次跳转、其他目的域、端口、
userinfo、HTTP和非对象视频路由均拒绝。没有通用代理或浏览器自选URL。
原静态资源来源继续保留，大小、图像尺寸、超时与作用域复核不变。
