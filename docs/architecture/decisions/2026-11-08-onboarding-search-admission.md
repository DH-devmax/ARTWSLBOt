# 接入账号搜索与好友发送准入分离

2026-11-08。v77在读取精确目标之前检查发送开关，并在准备记录插入时
要求开放准入，导致发送关闭时连只读搜索和已有好友路径也被拦住。

控制层继续校验网站申请人、空间、平台、账号版本、epoch和当前连接，
显式执行有界原生精确查找后密封固定一个目标。准备记录的`gate_version=0`
仅表示尚未提交，没有执行权限。已有好友直接继续独立认证私聊证明。

本人确认提交时，控制层在同一事务中检查当前开放准入，并把准入版本、
幂等键和一次预算固定到原操作。此后版本不可变；最终原生提交仍重新核验
该版本、网站会话、目标、连接、期限和账号冷却。未决结果只核对原操作。
只读状态返回独立的发送阻塞原因，不污染整个挑战的身份与群证明状态。

061为前向兼容迁移，保留060及已有历史。零版本只允许未提交准备或当前
好友投影；更新时只能在首次`prepared`到`submitting`转换固定开放版本。
其余作用域与预算不可变约束保留。旧API回滚时无法提交新零版本准备，
数据库拒绝此转换，避免回滚放宽准入。

后台账号工作台提供有版本校验的超管准入编辑弹窗，复用既有控制层接口。
用户中心不通过前端身份、按钮或工作区获得准入维护权限。
不增加服务、依赖、数据库连接、助手工具、自动审批或批量发送。
