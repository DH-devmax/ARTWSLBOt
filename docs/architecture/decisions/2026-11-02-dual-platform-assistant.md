# 双平台单群助手与本人确认

状态：依照用户2026-11-02方案实施的候选，部署及验收结果另记测试报告。

## 决策

Web群管助手面向网站用户，旺商聊与辣椒聊各自解析平台能力。可信范围固定为
网站会话用户、租户、平台、授权群及当前绑定的管理机器人。浏览器和模型只能
提出待校验的群标识，不能指定可信租户、权限、执行人或账号归属。
共享号池不共享群权限；非租户主账号仅可见明确分配的群。
群列表按平台分页，每页最多50，产品最多300群。未选群不启动模型。

参考 ChatWithEino 固定修订 `00ad7425513ff231b7467e88f5eeecde3c440bed`
的会话、流式事件、人工确认与取消交互；未复制开放 Agent 工具或运行时。
已从 `cloudwego/eino-examples` 固定检出核对
`quickstart/chatwitheino/server/server.go`、`mem/store.go`、`a2ui/streamer.go`
及第7、11章。参考项分别是会话标题、历史只读渲染、流式事件、审批与中止分离。
本项目采用数据库密封计划及独立人工控制事务，保留已有Eino版本和有界回合；
不移植示例的JSONL存储、每会话TurnLoop、自动重试、开放工具或明文内容日志。
保留 Eino v0.9.22、三次模型、六次顺序工具、90秒和原并发、费用冻结上限。
助手不是群内热群机器人，也不增加独立超管 AI。

`internal/assistant` 仅有标准库的有界编排和固定工具协议，
`assistantadapter` 适配 Eino；`control` 持有授权、密封、预算和持久事务。
查询、历史、卡片、SSE与确认均检查当前授权指纹。模型只生成建议。
等待确认后结束模型运行，没有每用户或每群常驻任务。

## 配置与原生动作

配置仅包含拦截词、黑名单、豁免和关键词回复的已支持字段及开关。
本人确认使用既有版本化保存事务；保存与实际生效分开展示。
原生动作目录归 `internal/features`，平台、实现、权限和生产准入分别判断。
首批范围为群资料、公告、名片、成员和全群禁言、解禁、踢人、群文本及撤回。
尚无持久执行底座的能力不注册写工具。平台生产验收未通过的动作保持阻断。
管理员任免、邀请、退群、全局账号维护、财务和抽奖写入不进入工具。

成员候选最多20项，服务端签发绑定本人、平台、群和授权指纹的密封短期票据；
歧义时需用户点击选择。不得从模糊名称直接构造目标。
撤回消息从当前群最近两分钟的已解码消息中有界查找，返回最多20项摘要；
即使只有一项，也须本人选择。密封引用绑定原事件与源摘要，不返回正文或路由凭据。
动作建议为独立10分钟密封计划，绑定本人、目标、参数、摘要、版本和epoch。
确认接口仅接收计划编号、摘要、版本和幂等键。重复确认返回原结果，不重发。

普通业务准入与超管受控测试准入独立；前者必须同时满足显式动作权限、
套餐模块、有效群绑定、当前角色及平台生产准入。只有控制层能构造私有业务准入，
然后进入既有持久原生执行与最终栅栏。模型不能创建授权、使用测试窗口或native_debug。
未知提交只查询原持久编号；重启不继续执行旧计划。
