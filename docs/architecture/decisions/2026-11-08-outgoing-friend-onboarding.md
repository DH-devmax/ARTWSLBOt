# 双平台统一主动好友接入

历史决策：本文件中的客户主动申请方向已由同日后续
[传入联系人接入决策](2026-11-08-incoming-contact-onboarding.md)替代。
保留原实现与历史证据说明；原生能力现仅供持久受控测试。

2026-11-08，用户确认两平台放弃依赖传入好友申请附言的认领入口，
统一为机器人主动申请、用户在 App 接受、独立私聊核验和群内归属证明。

`internal/control/group_binding_outbound*.go` 持有网站身份、空间、平台、
机器人、单目标、期限、幂等、一次尝试及最终提交校验。准备目标只执行有界读取，
本人确认才提交原生变更；页面 GET 不搜索、不发送、不核对上游。
`internal/gateway/onboarding_outbound*.go` 复用账号读取队列、连接所有者和限流，
`nativeauth`、`lajiaoliao` 分别实现自己的固定客户端契约。

独立前向迁移060保存密封目标和操作。`submitted` 仅表示平台申请回执，
`friends` 仅表示当前好友关系；二者均不写入网站身份或群归属证明。
已固定目标时，后续认证私聊及群内挑战只能由同一原生身份满足。
取消、过期和重启不产生发送重试；未知结果保留原操作以供只读核对。
写入冷却在队列及新鲜读取完成后预留；完整适配器返回前不记录成功回执。
明确匹配原申请的拒绝可收敛为失败。残留提交仅在其原始期限及有界最终栅栏
均结束后允许在线核对，不能借核对重新发送。
旧入站审批停止新提交，原记录和未知结果核对保留。

助手、热群与自动群管没有好友搜索、主动申请或审批工具。新的账号级接入准入
与旧审批准入、群业务准入、受控测试授权相互独立；真实平台验收未通过不视作开放。
本变更不改变接收 ACK、解码器、公共消息密封格式或全局 readiness。

账号查找的失败阶段及安全原因由原生适配器产生，控制层在交付和审计前重新
核验网站身份、挑战期限、版本与账号作用域；HTTP只投影固定枚举及有界业务码。
读取错误与原生申请提交错误分别处理，避免发送前读取被误记为未知变更。
不向模型或审计开放查询账号、响应正文及凭据。真实-1拒绝的事实和边界见
[接入诊断](../../onboarding-search-diagnostics-20261108.md)。
