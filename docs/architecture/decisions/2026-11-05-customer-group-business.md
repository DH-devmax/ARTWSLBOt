# 客户接入与群管业务

决定日期：2026-11-05。来源：项目所有者确认的客户接入、权限分控与双平台群管闭环方案。
本文记录批准的边界；部署、性能和真实原生效果以本轮测试报告为准。

客户通过一次性网站邀请成为租户负责人。网站邀请不等于套餐开通，也不证明原生群归属。
接入证明来自已认证、持久化的原生挑战消息和当前群角色。原生群主确认后可绑定，
原生管理员的申请交超管审核。恢复、转移和新绑定均重新核验，绑定后保留配置、关闭业务。

负责人管理成员与群范围，只能在超管能力上限内授权。成员角色名称不隐含群访问权，
旧的 `members:manage` 委派不再赋予成员管理权。权限最终取平台准入、有效套餐、超管上限、
租户授权、明确群范围、字段授权、运行状态与当前原生角色的交集。

助手、自动规则、接入向导、热群聊天和受控测试分别准入。正式入口按平台、来源、动作
设置关闭、指定群灰度或开放。超管可以用同一助手选择所有有效绑定群，保留自己的会话
和测试费用范围；其正式原生操作仍受目标群套餐、绑定、角色和来源准入限制。
助手和后台业务不能获取 `native_debug` 或创建受控授权。

首批自动业务只包含：

- 拦截词：普通成员消息字面包含命中后撤回当前消息。
- 业务黑名单：普通成员发言后禁言十分钟，同周期不重复提交。
- 豁免名单：业务豁免、当前群主、管理员及号池机器人跳过自动处置。
- 关键词回复：按保存顺序取首个字面包含匹配，一次发送一条不超过4000字节的文本，
  默认每群冷却30秒，保留仅管理员触发设置。

挑战消息单独处理，自动处置优先于关键词回复，命中时抑制热群回复。业务消费发生在持久
投影之后，不进入接收提交与 ACK。消费者使用固定有界工作池、独立持久任务与发送尝试；
配置或运行关闭时不创建任务。启用前历史不执行，晚提交通过持久去重与回扫处理。
执行前重新核验配置版本、授权、角色、账号 epoch、连接所有者和期限。

未知提交只核对原编号，不自动重放。接入接受邀请也遵循此规则：证明邀请人后匹配指定群、
指定机器人、指定邀请指纹，由客户确认一次；证据不足或歧义转人工处理。

本轮不增加服务、数据库连接池、缓存服务或每群常驻 Agent；不改变解析算法、密封格式和
`CodecVersion=7`。长期记忆、学习和扩展仍独立关闭。全局 readiness 不随部署提高。
