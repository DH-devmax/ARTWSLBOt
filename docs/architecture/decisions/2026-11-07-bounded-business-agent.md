# 有界业务 Agent 与模块显式开放

日期：2026-11-07。状态：已实施并部署；真实效果及未验收项见本轮测试报告。

业务和平台动作事实源继续属于 internal/features。assistant_modules 提供编译期 opt-in 投影，平台策略、产品范围、套餐、租户上限、成员字段权限和正式来源准入互不替代。新增模块默认不成为模型工具。

assistant 核心只负责有界编排与内嵌只读中文指引；Eino 仍只在 assistantadapter。control 解析网站作用域、提供白名单查询、生成不可变密封建议，并在本人确认及最终提交重新验证。模块开放不启动自动任务，也不授予 native_debug。

模块开放策略按平台单独持久化，以CAS版本维护。版本进入回合与新计划的密封摘要。关闭或改变策略阻断旧回合内容和未提交计划；已提交记录按原权限继续核对，不重发、不追加模型调用。旧计划不重写摘要，缺少策略版本的待确认计划失效。

历史按会话读取最近10轮，计划记录去重后批量取出；请求内投影复用，交付前重新鉴权。查询事实带来源和采样时间，候选目标使用已有结构化选择，历史文字不构成当前身份或执行权限。不存在跨请求的明文结果缓存。

结果解释属于控制层事实投影：平台成功回执、接收侧观测、用户已读是不同证据。发送观测按原始client ID、发送原生身份、群、平台和原生消息ID匹配已有持久事件，读取有界，不调用原生接口。

新增059前向迁移，保留既有执行与费用账本、CodecVersion=7及Compose服务集合。没有开放式主机工具、动态插件或第二套Agent执行器。
