# 双平台隔离测试准备

依据所有者2026-11-03要求：禁止批量原生调用，优先核验旺商聊既有样本和
自有成员的管理员升撤权，同时补齐辣椒聊既有测试群授权与连接状态核查。

受控动作准入对两平台使用同一组身份、管理用途、测试开关、现有接收连接、
租约及心跳检查，账号与群必须同平台。页面查看不启用连接或提交动作。
普通租户认领保留一次码和身份核验流程，不据原生群主身份猜测网站所有者。

所有者委托的隔离原生测试可由超管显式指定已有确认网站所有者的测试租户，
通过独立`test-binding`准备接口建立一个单群绑定。必须显式确认隔离和身份、
核验版本、测试与动作准入、当前原生角色，遵守共享容量锁与账号30群上限。
已有绑定或未决认领阻断该准备；不会改写网站所有权或替换现有绑定。
该事务仅设置isolated_test及关闭业务的绑定，审计真实超管与确认网站所有者。
不创建套餐、动作窗口、原生操作或生产执行准入。

原生变更继续使用独立持久`native_debug`窗口，当前轮次单目标、300秒、两次预算；
窗口有效不替代提交时的原生角色及最终栅栏。正式`package`准入和助手权限不变，
测试准备不注册为模型工具，也不由热群引擎调用。
