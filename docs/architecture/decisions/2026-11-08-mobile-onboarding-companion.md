# 旺商聊接入搜索使用独立手机业务会话

用户要求补齐手机认证和搜索适配。桌面认证、接收和手机号池身份仍为原有
2.8.3，增加Android3.7.4业务伴随会话，代替只改请求头或复用桌面JWT的做法。
该决定只扩展接入搜索认证，不恢复旧的通用移动接入器。

`nativeauth`持有固定手机密码学、认证及好友接入白名单；`httpapi`持有超管
认证事务和密封保存；`gateway`根据既有账号恢复手机搜索客户端；`control`
仍持有申请人、空间、目标、准入、预算、幂等及最终提交。手机客户端不取得
NIM票据、不注册接收连接，不改变账号的唯一连接所有者。

新增062保存独立配置和会话。账号、UID、epoch、部署及会话版本都参与校验，
手机版本进入接入证据和最终事务栅栏；替换和撤销在锁内检查未决申请。
请求编号复用既有持久高水位，避免两套配置共享正文密钥时发生nonce冲突。
不增加生产服务、数据库连接、后台登录任务、助手工具或批量好友操作。

合成、真实认证、搜索及主动申请分别验收。桌面1001不能证明平台停用原因，
新适配也不构成绕过原生准入或自动提高readiness的依据。

同日响应契约修正：手机认证不读取仅桌面必需的响应票据作为交换回显。
请求X-Context及加密响应关联保留，业务MAC按固定Android SDK从签名公钥派生。
响应号码只作有界资料一致性检查；身份授权仍由HTTP保存事务中的既有UID、
网站会话和版本栅栏完成。手机失败诊断复用原安全记录器，不新增敏感日志、
数据表、后台重试或执行入口，所有权边界不变。
