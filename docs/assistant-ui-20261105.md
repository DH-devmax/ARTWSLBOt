## 界面与交互

- 超管用户中心侧栏标题改为“后台管理”，使用橙／红／黄三色三角标识，
  按用户提供的4秒循环变色与浮动效果实现，缩放到32px并支持减少动态效果。
  普通用户仍显示用户中心；两平台保留自己的名称和标识。
- 删除侧栏“平台管理／个人服务”作用域标签和“等待同步”页脚。
  顶栏刷新和原有后台同步行为保留。
- 群管助手从导航分组中移到品牌区下方的独立入口，保留原顶栏弹出入口。
- 对话参考 [TanStack AI Vue 示例](https://tanstack.com/ai/latest/docs/framework/vue)，
  使用现有 Vue、Element Plus X 和 Fairweather 主题，未引入新的 Agent 或模型运行时。
  桌面显示授权群／历史侧栏，手机用群选择面板和历史抽屉；工作区铺满可用宽度。
- 历史以首次提问命名，支持搜索、单条删除、当前选中状态。回答支持复制，
  长记录可回到最新消息。保留最近10轮、同范围唯一空白新对话和切群草稿。
  查看、选群、复制、取消删除均不发起付费模型或原生操作。

- 认领状态修复（v70）：普通用户只列出归属有效且本人获分配的群。超管可见的
  未认领群标为只读，查询仍可用；本人有效测试认领显示“测试认领 · 可管理”。
  帮助弹窗同步展示当前权限，解除或失效后不保留旧的建议／确认入口。
  具体校验及真实验收边界见[群归属说明](assistant-group-ownership-20261107.md)。
- 手机端平台与当前群使用同一行，群列表按需展开；顶部与输入区减少固定留白。
- 输入框从1行自动增长至5行，继续输入在框内滚动；保留中文输入、回车发送、
  禁用状态、草稿恢复及8000字节提交限制。测量和宽度观察在卸载后停止。

- 能力说明是带采样时间的快照，不是执行授权；切平台、群、网站用户或空间时
  清空并关闭，旧响应不得覆盖新范围。确认时沿用后端实时权限与准入检查。
- 注入回归使用合成模型、工具结果和隔离`wsl_test`，验证禁用工具、跨群参数、
  伪造超管和自然语言“自动确认”不会获得执行权限；不据此宣称任何模型绝对防注入。

## 富文本与过程展示（2026-11-07，v68）

回答复用既有Bubble，正文使用锁定的markdown-it组件；支持标题、表格、列表、
引用和代码，禁用原始HTML及远程图片。表格和代码在移动端局部滚动。
每轮查询工具按返回顺序显示在默认关闭的原生details“处理过程”中，键盘可操作；
最终回答位于过程之后并保持展开。选择成员／消息和本人确认卡片保持在外，
可信执行结果按字面文本展示，失败或未知结果不随过程一起隐藏。
历史对话同样使用此布局，无需迁移、重放工具或补模型调用。

新增合成用例`tools/assistant_rendering_ui_smoke.js`覆盖两平台四视口、
流式顺序、HTML／外链边界、键盘折叠和交互卡片可见性。部署和实测以
[测试报告](test-report.md)最新v68记录为准。

## 删除边界

新增 `DELETE /api/v1/assistant/sessions/{id}` 和前向迁移049。
删除需要当前网站用户、平台及群授权，不能借用同租户他人的会话。
有正在生成的回合或提交中的操作时返回409；用户先停止生成或等待操作完成。
删除成功清除标题、问答密封正文、事件和成员候选，取消待确认的配置及动作建议。
会话、回合、SSE及建议读取均拒绝交付已删除内容。

保留回合幂等和每日用量计数、费用预留、已提交或未知原生操作及安全审计，
重复 DELETE 仅核对原结果，不再次记账或写审计。原七天清理期限保持不变。
迁移仅增加可空字段和部分索引，不修改已应用迁移；回退旧镜像可能重新显示空的
已删除会话，应优先前向修复，不能恢复已清除正文。
