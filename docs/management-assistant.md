## 边界与调用方向

`web/src/wsl/assistant` → `/api/v1/assistant` → `internal/control` →
有界 `internal/assistant.Runtime` → Eino 适配器 → control 统一网关 → 专属业务模型。

- Runtime 只得到绑定网站会话的 Host，不获得数据库、原生 transport、财务或主机接口。
  架构检查禁止引入 control/database/gateway/heatbot/插件等非标准依赖。
- Host 每次检查网站会话、用户、当前权益、所选平台域和资源归属；
  客户继续检查显式助手权限与套餐，超管本人使用服务端演示权益。
  模型参数使用严格 JSON，不接受可信身份、角色、租户或工作台参数。
- 每回合保存授权指纹（角色/权限/套餐版本/可访问账号与群的版本和epoch）。
  权限或资源改变后，历史正文与卡片一起拒绝交付，避免模型引用旧数据泄漏。
  这是保守失效策略；用户需发起新回合，不能回退到旧授权。
- 租户读取走受限连接与事务局部 tenant/actor/domain。会话、事件与计划按本人隔离。
  月度用量唯一例外是受限聚合函数：只返回当前事务租户的两个计量数，不暴露他人行。
- 不读取全量聊天记录，不调用 heatbot/MaiBot，不提供主机或开放 Agent 工具。
  四类现有群规则可建议修改开关和字段；模型不能保存或执行。
  原生动作由独立本人确认路由进入控制层，逐平台生产准入未通过时拒绝提交。
  原生和 AI readiness 均保持 false。

## 权限和套餐

`assistant:use`、`assistant:propose`、`assistant:approve` 不进入旧 manager/operator/viewer
继承模板。普通用户必须显式获得授权，且套餐包含 `management_assistant`。
原生建议和确认另需 `assistant:action_propose`、`assistant:action_approve` 和
具体 `group_action:<action>` 权限；不会从旧角色或受控测试授权继承。
四个权限模板分别为只读、配置建议、配置本人确认、群管本人确认。
超管本人使用永久演示权益，不受商业套餐和个人测试积分额度限制，
仍受平台总预算、网关开关、费率核验、并发及运行上限限制。
后台网关测试的单次预算和测试月预算保持原规则。

历史套餐的 `monthly_assistant_tokens` 和 `monthly_ai_tokens` 不转换、不赠送新积分。
商业PRO 每720小时发放10,000积分，两种AI共享；PLUS没有AI能力。
全局设置默认 enabled/tenant_access/approvals_enabled 全关闭，月额0。
开关只向超管开放；模型、密钥与费率只由统一网关管理，独立 AES-GCM 密封，
不返回、不写审计，不复用 CodeBoarding 密钥。
保存配置不等于运行启用或兼容验收。

客户审批还取字段权限/模块的交集；超管本人使用演示权益，不套用客户字段上限。
两者均复核最新原生管理员角色（native来源、60秒内观察）。
记录过期时，仅在通过本人审批权限、计划、套餐、版本和模块检查后补读一次
当前群角色，最长8秒。补读前释放数据库事务与生命周期锁，结果返回后重新
进行全部确认检查；新证据须在5秒内并匹配当前账号、连接、部署和原生群。
较新的持久角色、角色变化及群主证明冲突阻断旧计划，不重定范围或延长认领。
读取失败、取消或超时直接返回；不自动重试，不假定管理员。查看历史、刷新
和已提交计划的幂等核对不触发这次读取，也不追加模型调用。

## 工具

单群会话的工具由control生成绑定版本：查询传`{}`，配置建议只传本次读取的
`base_version`和`changes`，不让模型重复指定平台、机器人或群。旧同范围ID调用
继续兼容，越界ID、未知字段和无作用域请求仍拒绝；当前权限及版本仍实时检查。
业务指引版本为business-agent-v1.3，连续保存后重新读取当前版本，不复用旧快照。

| 工具 | 返回 / 限制 |
| --- | --- |
| `list_authorized_bots` | 作用域内已授权群对应账号的安全状态；不含接收遥测或凭据 |
| `get_bot_status` | 指定可访问账号的采样投影，不编造缺失性能指标 |
| `list_authorized_groups` | 本范围活跃授权群，最多100项 |
| `get_group_config` | 本范围且允许字段的安全配置；无原始会话或AI设置 |
| `list_group_operations` | 最近20项 kind/status/result_code/时间，不含目标、正文或财务 |
| `propose_group_config_change` | 只允许明确群作用域、基础版本匹配和未截断配置 |
| `get_group_capabilities` | 当前平台、群、本人权限下的动作目录及阻塞原因 |
| `find_group_members` | 当前群最多20名匹配候选；同名时需本人点击选择，不猜目标 |
| `propose_group_action` | 产生10分钟密封动作计划，不执行；仅注册当前显式授权且已实现的动作 |

超过结果上限只返回 `truncated=true`，不从残缺规则集生成计划。
群名、规则、工具结果和用户输入均作为不可信数据。正文按纯文本显示；
卡片仅由固定注册表和运行时 Schema 接受，不执行 HTML、Vue 或模型代码。

允许的审批字段仅为：
`blocked_words.words`、`blacklist.members`、`exemptions.members`、
`keyword_replies.rules`、`keyword_replies.admin_only`，以及这四类功能的 `enabled`。
没有 apply 工具；审批 HTTP 路由不注册给模型。
传统完整配置、字段配置和审批共用 `ValidateFeatures` / `CommitGroupConfigTx`，
字段接口与审批进一步共用 `SaveFeaturesTx`；不伪造内部 HTTP。

## API

统一 Cookie / CSRF / Origin / `X-Workspace: wsl|lajiaoliao`；回合 POST 和审批 POST 必须带幂等键。
资源ID仅是待检查目标。写入响应未知时先用原回合/计划ID查询。

| 路由（前缀 `/api/v1/assistant`） | 方法 |
| --- | --- |
| `/settings` | GET / PUT，超管、版本CAS、密钥留空保留 |
| `/health` | GET，超管，活跃回合/共享网关待核对数与采样时间 |
| `/usage` | GET，客户本人账期积分用量；超管本人演示用量按上海自然月，兼容字段附 unit |
| `/context?group_id=…&search=…&offset=0&limit=30` | GET，本人授权群、能力、权限及阻塞原因；每页最多50，最多300群范围 |
| `/sessions?kind=…&account_id=…&group_id=…` | GET，仅本人及当前范围 |
| `/sessions` | POST，显式 overview/account/group |
| `/sessions/{id}` | GET / DELETE，本人及当前群授权；DELETE 可按原ID核对 |
| `/sessions/{id}/turns` | GET / POST，服务端输入哈希校验幂等键 |
| `/sessions/{id}/transcript` | GET，本人当前范围最近10轮的有序正文、卡片与持久事件游标 |
| `/turns/{id}` | GET，状态与获授权的本人输入 |
| `/turns/{id}/events?after=N` | GET，SSE；`format=json` 为有界重放页 |
| `/turns/{id}/cancel` | POST，显式取消，不把退订当取消 |
| `/plans/{id}` | GET，审批结果对账 |
| `/plans/{id}/cancel` | POST |
| `/plans/{id}/approve` | POST，仅计划ID、服务器摘要及版本 |
| `/sessions/{id}/target` | POST，本人选择服务端签发的候选，密封令牌随下一回合传递；模型不能代选歧义目标 |
| `/action-plans/{id}` | GET，重新校验权限并核对原持久操作 |
| `/action-plans/{id}/cancel` | POST，仅取消尚未提交的计划 |
| `/action-plans/{id}/approve` | POST，本人、摘要、版本、幂等键；不接受账号、身份或新参数 |

事件包含 turn_id 和递增 seq；固定为开始、文本增量、工具状态/卡片、用量和终态。
不发送思维链。前端刷新先查状态，再订阅既有回合；断线可按最后序号重订阅，
不重新创建回合或扣费。事件单页50项、最多512项；最后一个槽保留给终态。
历史以有序快照读取全部保留事件的文本；恢复正在执行的回合从快照游标订阅，
已完成回合不再订阅。请求取消与代际检查共同阻止切群后迟到内容进入新群视图。
SSE 单独100秒请求范围、5秒写超时、四个订阅槽。
Nginx 只对精确助手事件路径关闭缓冲、放宽读超时，其余接口15秒不变。

- 全局2、用户1、租户2并发，无无界等待队列；每回合90秒、最多3次模型与6次工具；
  单工具3秒，输入8000字节，结果24000字节、输出上限2048 Token。
- 每用户最多100个七天内会话、每天200回合，避免零费用失败请求无限占库。
- 每次模型调用前，用数据库事务锁原子预留平台及租户当月预算。
  月界固定 Asia/Shanghai；等待模型期间无数据库事务。
- 有 usage 才按实结算。缺失 usage / 中断 /未知响应保留对应预留，标为 estimated/unknown，
  不是零消耗；重启也不能释放未核实额度。缺失凭证需人工对账，不伪造退款。
- 专属模型只能使用平台配置的 HTTPS 来源、固定 `/chat/completions`。
  DNS 所有结果必须公网，按已校验IP拨号且保留TLS主机校验；无环境代理、跳转或任意HTTP工具。
  429/超时/未知提交不自动重试付费请求。
- 重启将未完成回合标记 interrupted，不自动续跑；保留已有事件供查询。
  显式取消传播到 HTTP 模型请求并阻断后续工具；已消耗费用不自动归零。
- 计划10分钟有效、内容密封不可变，绑定用户、账号、群、版本和epoch。
  审批配置、队列失效、执行证据及最小审计同一事务；重复审批返回原执行ID。
  COMMIT响应不确定返回 `assistant_commit_unknown`，只能查询，不盲重试。
- 返回“配置已保存，实际生效尚未验证”；不声称发送、禁言、启用或已应用。
- 原生计划与配置计划分表。本人确认后，控制层重新校验权限、套餐、绑定版本、
  epoch、原生角色、期限和逐平台生产准入；共享既有持久原生操作与最终提交栅栏。
  不创建测试窗口，不使用 `native_debug`。提交未知只读取原编号；重启不重发。
- 042扩展原助手表的平台域及父子一致性；043新增动作计划与本人候选选择。
  旧记录仍为 WSL；旧费用、密封格式和已应用迁移不变。
