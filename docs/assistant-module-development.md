# 群管业务 Agent 模块接入

目录版本：business-agent-v1；产品指引：business-agent-v1.3。本文描述实现契约；
当前发布及真实验收以测试报告为准。

## 六层职责

1. `internal/features/assistant_modules.go` 从业务与平台动作目录生成编译期能力描述，保持稳定 ID。目录注册不会开通助手。
2. control 上下文解析网站用户、空间、平台、绑定机器人和单群；只交付当前权限可见的事实。
3. `internal/assistant` 处理有界业务对话，不持有数据库、原生执行、供应商密钥或主机权限。
4. `internal/assistantadapter` 保留 Eino v0.9.22，三次模型、六次顺序工具、90秒。
5. control 生成密封不可变计划，本人确认经同一控制层及最终原生栅栏执行。
6. 结果投影从持久计划和接收事件解释结果；不依赖模型编写成功结论，不额外调用模型。

## 新模块步骤

- 先在业务目录登记产品范围、平台实现及字段，原生依赖与真实验收分别维护。
- 在 `AssistantCapabilities` 中显式登记模块 ID、类别、工具、权限和版本化输入输出契约。未适配模块不注册。
- 只允许 `query`、`config_propose`、`action_propose`。查询需有界；建议复用版本化配置事务或已有持久动作，不新增直接保存、发送或执行工具。
- 控制层新增适配器和严格参数校验，绑定服务端作用域；结果复用 `ToolResult` 的 `type/scope/sampled_at/verification/truncated/data`。候选引用必须重新核验，不能从名字推断身份。
- 权限目录自动加入 `assistant_module:<module>:<category>`。平台通过版本化 `/assistant/module-exposure` 显式开放；负责人只能在租户上限内再分配。角色、套餐及已有业务模块不自动赋予这项新权限。
- 配置建议按每个 feature 核验开放和字段权限；动作建议还检查逐动作权限，执行另查正式来源准入。平台相互独立。
- 前端增加类型化业务字段和安全展示，不渲染模型 HTML 或任意执行卡片；编辑放入作用域弹窗。
- 补默认关闭、只读开放、跨平台／群／用户、关闭旧计划、撤权、重复确认、未知结果及迟到事件回归；生成目录并运行现有发布检查。

## 策略和历史

新增059前向迁移。每平台默认空能力列表，管理接口仅超管可读写，CAS版本校验。配置和动作计划的策略版本纳入密封内容及摘要，确认和最终提交重新核验。旧待确认计划没有版本时拒绝提交；已提交记录保留原编号核对。

回合记录策略版本，策略变化后停止旧回合及其正文／查询卡片交付；仍按当前业务权限投影已提交计划结果。近10轮在字节预算内包含带采样时间的查询事实和最新计划结果；它们是历史数据，不能授权重放。候选 token 不作为可复用历史身份。

历史投影先按会话去重计划编号，再分别批量读取配置及动作的密封记录。同一计划在一次请求内只投影一次；该请求快照不跨用户、平台或请求复用，交付前再次校验会话、权限指纹与开放版本。审批始终重新读取并锁定持久状态，不使用历史快照提交。

内嵌 `internal/assistant/guides/agent.md` 是只读产品指引，版本用于追踪，不是授权依据。不会读取仓库开发 AGENTS.md 或运行时用户文件。

## 单群参数契约

control按当前会话生成`GroupTools`：查询机器人状态、群配置、操作记录以及
列表工具均使用空对象；配置建议只传最新读取的`base_version`和`changes`。
平台、账号、群、用户和租户从服务端会话解析，不要求模型从旧正文重新找ID。
保存后的旧正文继续失效，下一回合用当前绑定重新读取，不放宽历史鉴权。

控制层兼容旧调用中的同范围ID，显式跨群、跨账号及未知字段仍拒绝；空参数
不能用于空作用域或跨平台回退。旧overview工具仍要求明确资源参数。
建议仍须最新版本、能力开放、字段权限及独立本人确认。没有参数修补重试、
额外模型调用或直接执行入口；失败调用不能被解释成保存成功。

绑定单群的只读查询兼容上游省略或只给空白参数，此时本地按空对象解析。
非空参数仍必须为严格JSON对象，null、数组、字符串、尾随数据及未知字段
明确拒绝，不通过删除字段兼容。工具开始事件只新增固定argument_format
枚举，不保存原始参数、字段名或值。不可用工具、参数格式和资源选择错误
分别返回固定安全错误码；旧回合没有该形态字段时不能反推原始参数。

## 执行证据

`status` 是持久操作状态；`evidence_state` 独立表示待确认、提交中、平台成功回执或接收观测。发送观测按持久 client ID、发送原生身份、群、平台及原生 server ID 匹配，最多100条／2MiB、1秒，范围限发送时间前1分钟至后5分钟。优先核对发送后最早的记录，再检查时钟偏差窗口，避免较新的无关事件挤掉早期回执。查询不访问上游、不重发；达到查询边界、缺失或被保留期清除的数据不能证明未送达。接收观测不是用户已读。

可选 `observation` 返回事件编号、原生消息标识和观测时间；不输出 nonce、凭据或原始上游正文。
