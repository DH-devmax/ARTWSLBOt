## 已接入的链路

| 范围 | 原生契约 | 控制与界面 |
| --- | --- | --- |
| 成员禁言、解禁 | `mute_group_member` / `cancel_mute_group_member` | 持久Tools、当前角色复核、最长5分钟受控禁言 |
| 全群禁言、解除 | `mute_group` / `cancel_mute_group`；status 0/2 | 持久Tools、当前群状态回读 |
| 移出成员 | `kick_group`；`kickedUserIDs`、`permanentBan` | 普通移出和永久禁止申请进群分别授权；禁止本人、群主及无权限目标 |
| 原生群禁入 | `get_group_permanent_ban_list` / `remove_group_permanent_ban` | 按需完整分页及独立解除授权；与业务黑名单、好友黑名单分离 |
| 公告 | `set_group_info_ex`；`notification` | 单次持久修改；只读当前公告 |
| 授予、撤销管理员 | `set_group_member_info`；`members`数组、roleLevel 60/20 | 仅当前原生群主；分别核验目标现有角色 |
| 群内昵称 | 同接口；nickname最多15字符 | 单项弹窗及独立受控Tools，可调试本人昵称 |
| 好友目录、审批 | `friendsInfo.friendUser`；`add_friend_response` | from/to身份、申请时间、人工同意或拒绝及未知结果屏障 |
| 入群申请 | `get_recv_group_applicationList` | 当前群有界分页；不声称能取得邀请人或完整历史 |
| 邀请、退出 | `invite_user_to_group` / `quit_group` | 持久Tools；邀请好友不代表已入群；群主不能直接退出 |
| 本人接受邀请 | 本人申请侧列表及 `group_application_response` | 独立group_accept授权；来源2、非本人邀请人、唯一待处理记录；本人确认和持久结果核对 |
| 昵称 | Chat `/user/update` | 本人单项弹窗及持久控制 |
| 性别、生日、签名 | Chat `/user/find/full` / `/user/update`；gender 0/1/2、毫秒时间戳、80字符签名 | 仅查询本人业务资料；逐项保存、空签名可清除；地区名称只读 |
| 原生消息通知 | Chat `/push_config/get` / `/set` | 新消息、详情、群消息、振动四个开关；提示音保持原值，不猜测枚举 |
| 修改密码 | `/account/code/send` purpose 2 → `/account/password/reset` | 服务端读取本人绑定手机；验证码与新密码MD5一次提交，不套用旺商聊旧密码步骤 |
| 换绑手机 | purpose 6旧号发码 → `/account/code/verify` → `/account/contact/check` → `/account/contact/change` | 新号发码人机场景7；当前仅已绑定中国大陆手机号；新号与流程密封绑定 |
| 搜索、好友策略 | Chat `/friend/privacy/get` / `set` | 原生账号/手机搜索；好友需审批、允许、拒绝三种策略 |
| 群邀请、通话策略 | IM `/user/update_user_info_ex`，合并本人ex | 群邀请允许/拒绝；`disableAudioVideoCalls`反向开关，不改其他ex字段 |
| 引用、@、合并记录读取 | 114、106、107；有界嵌套结构 | 消息页按需读取原始密封记录，核对原投影身份与会话；深度3、总32项 |

角色修改以固定桌面App调用`setGroupMemberInfo`的条件和随包SDK路由为依据；
共享OpenIM proto仅作合成契约回归，不单独作为辣椒聊支持的证明。
响应中的正常status和待处理handleResult允许proto3省略的零值；缺失列表仍拒绝。
目录每页100项、最多100页；不完整分页或重复成员不用于执行授权。

## 调试与用户业务

受控Tools限超管显式持久授权。`native_debug`可以在商业套餐与群业务关闭时
调试已实现动作，仍检查活跃租户群绑定、账号平台、epoch、当前角色、目标、
有效期和次数预算。昵称调试只扩展辣椒聊的独立动作集，不扩大旺商聊授权。
用户的自动群管业务及群管助手没有创建测试授权或直接调用原生接口的能力。

提交只发一次。取消、账号变更、原生角色改变及网站会话失效均在最终栅栏重验；
未知结果持久保存，通过原操作查询和只读回读处理，不自动重发。
接收器继续使用已有连接所有者，不因设置读取或修改另起一条接收连接。
