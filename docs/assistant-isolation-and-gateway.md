## 当前边界与本批交付

共享网关由 Go control 持有密封业务密钥、不可变费率、队列和账本。
架构分析配置完全独立。用户和热群引擎均不能读取密钥、直接选择厂商 URL
或修改预算。当前群管助手支持两个平台，平台能力和准入分别判断。

已提供超管固定只读上游查询、单次模型测试和三种租户助手权限模板草稿。
模板不会自动分配、更新已有角色或给成员增加任何群。
“助手管理”仍是人工管理页面；独立的“超管助手”退出产品入口。
历史独立会话、密封正文和费用保留原含义，不能转成用户中心演示记录。
是否已部署、启用及真实调用通过，见测试报告。

## 上游预算与自动映射

保存来源时将 HTTPS 根来源规范到 `/v1`；仅接受根来源或 `/v1`。
查询只访问同一来源的三个固定路径：

| 路径 | 鉴权 | 处理 |
| --- | --- | --- |
| `/v1/usage` | 业务 Bearer key | 校验有效钱包、非负余额及明确币种 |
| `/v1/models` | 业务 Bearer key | 精确匹配模型 ID |
| `/api/provider/pricing` | 不传密钥 | 校验 schema 1.0、每百万 token、完整缓存价格 |

复用公开地址逐次校验、禁止重定向/代理的 HTTPS 客户端；每响应最多
256 KiB、每请求最多4秒；共用网关有界调度。不得输入任意探测路径。
查询前后重新校验网站会话、超管身份和当前 rate_id，更新期间变更来源/
密钥会使旧结果作废。只存选定模型的安全投影，不保存完整上游历史/错误体。
快照绑定不可变 rate_id；更换密钥/模型/费率即换快照范围。

自动映射遵循：

1. 钱包余额、密钥限额、滚动窗口、订阅额度与本地自然月预算是不同指标。
   本批仅适配明确的有效 `unrestricted` 钱包；其他格式标记未适配，
   不按零余额处理，不推测周期或重置日期。
2. 明确 USDT 余额可计算积分上界：`USDT × 1000 × 10^6`，向下取整。
   超管可显式确认当前路由的 `USD = USDT 1:1` 内部记账口径；此时
   USD 钱包也可按同式计算，原币种/余额仍保留。此口径与业务来源、模型、
   密钥一起保存在不可变密封费率快照，并记录审计；旧快照默认未确认。
   它是采样时的参考上界，不是可自动增加的本地预算。CNY 不因此换算。
3. 只有精确模型、唯一报价、每百万 token、完整普通输入/输出/
   缓存命中/写入价格均明确，且币种为 USDT 或当前路由已确认的 USD 时，
   自动转换为整数 micro-USDT 费率草稿，向上取整；仍需超管核对并保存新费率版本。
4. 同名多组、缺缓存价、缓存不同期限分档、未知单位、币种不一致均阻塞映射。
   不用缓存价缺失推断免费，不用统计消耗反推实时价格。
5. 本批没有后台轮询、自动改商业售价、自动加本地预算、自动充值或自动退款。
   后续连续同步应单独增加固定低频任务和过期状态；每次真实调用仍以不可变
   费率及本地预算预留为准。余额可被其他客户端消费，不能作为强一致额度。

2026-10-30 对所提供业务配置实查：钱包接口和模型列表可用；
价格接口返回 CNY 且无 `deepseek-v4.1-flash`。因此可以展示原币余额和模型
可用性，不能据此核定 USDT 费率或解除付费调用闸门。余额是采样值。

用户随后补充“充值 CNY 1:1 USD”及模型统计行
`deepseek-v4.1-flash | 15 | 124.27K | $0.019 | $0.313`。
其中充值口径不作为市场汇率。用户随后明确确认账面 USD 按 1:1 USDT 记账，
本批将其作为上述当前路由的显式设置；不推断 CNY 模型报价等价。
该行尚无列标题、计价单位及缓存价；本次“确认”也不能补出缺失的数字。
不能把统计消费直接当成每百万 token 单价，因此暂不填写四项已核验费率，
也不自动扩大本地月预算。真实设置/查询及部署状态见测试报告。

## 单次测试

只有当前无租户归属的超管可提交，固定提示词 `Reply with OK only.`，
无工具、最多32输出 token、45秒；整个 HTTP 入口55秒。
每次必须给出 rate_id、UUID 幂等键、正值单次积分预留上限（最多100积分）。
仍需网关/路由已启用、费率已核验、平台及超管测试月预算充足。
共享调度、预留、提交复核、不可变费率、usage结算及未知冻结不变。
保守预留仍按原2048输出上界；32 token 是实际发送的更小上界。

已存在幂等键只查询原记录。传输超时或未知结果不换键重放；
未知仍持有预留，只有证据充分的人工对账才能释放。页面不展示生成内容、
供应商错误体、密钥或推理。真实业务助手及租户灰度可以保持关闭。

## 历史独立超管助手方案

以下描述2026-10-30的隔离方案；当前超管使用用户中心群管助手，执行模式为
`operator_demo`，不会启用这一独立平台助手。

两类助手共享网关基础设施，分别拥有身份上下文、会话、工具注册表、
模型提示词版本、预算用途和页面。不能通过给同一代理切换 `is_admin`
提示词来获得平台权限。

| 边界 | 用户群管助手（当前已有） | 平台超管助手（只读 v1） |
| --- | --- | --- |
| 可信身份 | 网站会话解析的 tenant_id / actor_id | 独立超管入口解析的 actor_id；无默认租户 |
| 会话键 | tenant + actor + WSL + account + group/scope | platform + actor + 固定平台 scope；独立表/密封正文 |
| 查询内容 | 本人可见群、套餐/权限允许的安全配置投影 | 聚合健康、容量、匿名错误计数、发布/账本安全状态 |
| 模型工具 | 当前白名单查询/配置建议 | 固定 platform_health 汇总；无可调用模型工具 |
| 预算 | 租户当前720小时周期钱包及成员/群/用途上限 | 独立平台用途预算；不可扣租户钱包 |
| 写入 | 模型仅建议，本人显式审批走共享配置事务 | 模型无写能力；人工设置由独立 API 处理 |
| 禁止 | 跨成员会话、跨群记忆、共享账号原始消息、原生/财务动作 | 租户原始会话/附件/凭据、任意 SQL/HTTP/Shell、创建原生授权 |

当前后端把会话、事件、计划与网站 actor/tenant 绑定；普通租户角色不
继承助手权限。超管现有群管会话仍属于群管用途，并非独立平台 AI 助手。
跨成员审批未实现。平台只读助手使用固定 `purpose=platform_assistant`，
无 tenant/group，普通用户及其他超管均不能读取本人的平台会话。
客户端不能指定角色、租户、工具集或群管会话 ID。模型只能收到机器人/
认证账号/授权群/未决模型调用的计数和开关，不读取账号姓名、租户正文、
附件、凭据或配置体。平台预算仍受共享平台总预算限制，不使用租户钱包或测试月预算。

每问最多一次模型调用、512输出token、45秒，单次预留最多5积分，无自动重试。
问题最多2000字节；每人最多20个24小时会话，每会话最多20问。
当前每问独立取新快照，不将之前回合自动拼入模型上下文。
会话正文按 actor/session/turn 密封，过期不可读取；新建会话时清理本人过期正文。
同一幂等键仅查询原记录；执行中或未知时不能换键重发。撤权/取消/设置变化/
过期会中断网络等待；已提交但无可信用量继续冻结，重启不重放。
未知调用经人工对账后，原回合仅显示未完成，不补生成丢失的文本。

客户配置建议/人工保存的最终权限：
`网站有效会话 ∩ 显式权限/拒绝覆盖 ∩ 套餐 ∩ 成员群分配 ∩ 群授权 ∩
当前原生角色 ∩ 账号/配置版本 ∩ 截止时间/预算`。
角色名称不意味着群范围；非owner未分配群时可见群为空。角色/权限/
分配变更撤销会话和待执行工作。所有缓存、草稿、请求结果沿用相同作用域。
超管本人按当前演示权益判断商业权限；绑定、归属、账号epoch、原生角色、
来源准入、幂等和频控仍由共享控制层核验，自动任务不使用演示权益。

## 权限模板与 UI

以下三种 v1 模板由后端返回，租户主账号在“成员与权限 → 角色权限”
新建角色时选用；可检查逐项权限后人工保存、再分配指定成员与群。
套用仅替换未保存的新角色草稿。既有角色不随模板版本扩权。

| 模板 | 助手权限 | 可写字段 | 保存边界 |
| --- | --- | --- | --- |
| 助手只读 | use | 无 | 只能查询 |
| 回复规则建议 | use + propose | keyword_replies.rules | 只能生成本人建议 |
| 回复规则建议与本人确认 | use + propose + approve | 同上 | 人工确认本人有效计划 |

三者都仅含工作台/账号/群/操作记录读取；不含原生操作提交、完整群配置、
成员授权、平台管理、财务和受控测试。字段权限并不绕过原生管理员角色、
套餐或群范围；拥有建议权也不会让其他成员审批此建议。
更多禁词/名单编辑模板应按业务逐项批准，避免大包授权。

用户端保持“群选择 → 本人会话 → 建议差异 → 本人确认”路径。
超管端保持“助手管理 / AI网关 / 受控测试”独立页面，状态用 Element Plus
描述/标签/表格，预算趋势有真实时间序列后再复用 Art 图表。
没有来源的指标显示未提供；不绘制虚构余额趋势或把保存当运行。
未来跨成员复核需新增 `review_others` 权限、申请人/审核人双身份、
可见范围和防自审规则，再提供专门审核队列。

服务端建立平台会话时使用固定 `consumer=platform_assistant`；
客户端传入 tenant_id、role 或 toolset 均不能切换身份。用户会话固定
`consumer=management_assistant`。缓存键至少包含 consumer、tenant/平台、
actor、platform、account、group、权限版本；取回时再次授权。
两类助手共用调度器和可替换的模型路由，但不共享提示词正文、对话历史、
摘要、检索索引或付费预算。平台诊断若以后需要租户范围，应另外设计明确、
可审计、限时的支持授权，不能复用超管模型提示词绕过租户边界。
