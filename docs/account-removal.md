# 机器人移除与数据清理

删除入口位于顶部连接状态列表及工作台机器人列表的垃圾桶按钮，仅超管可用。
两个工作台各自处理自己的账号；预览只读，确认需输入完整机器人名称。
这会移除本平台接入并释放账号名额，不注销旺商聊官方账号，不发送退群或其他原生动作。

## 清理范围

- 物理删除账号、加密登录会话、原生身份映射、人设、密封模型配置及密钥。
- 删除该账号的收件箱正文、群关系、授权码、认领申请、已确认结果的注册记录和操作。
- 删除独立测试窗口；共享窗口终止并移除该账号及 epoch，保留其他账号的记录。
- 终止账号的注册/登录事务并清除认证管理器中的启动状态；迟到登录提交不得重新创建账号。
- 清理当前浏览器中对应账号及其失效管理群的草稿、选择状态与页面缓存。
- 删除与该账号关联的旧审计载荷，只新增包含账号 UUID、作用域及数量的最小删除审计。
- 仅清理该账号原先引用且已无任何其他引用的群目录，不扫描删除无关目录。

## 保留范围

群的租户归属不能因删除机器人而转移。删除群管机器人后，归属记录保留但停用，
清空管理配置、解除群管/AI 账号绑定并提升执行版本。删除热群机器人仅解除其 AI 绑定、
停用对应 AI，保留其他机器人的群管配置。停用归属仍可在群列表查看，不能自行重新认领。

财务台账、支付证据、活动及其参与记录属于租户业务历史，不随机器人删除。
已有财务记录的不可修改、不可删除权限不变。其他机器人、用户、套餐、共享协议配置
和原生请求编号水位不在清理范围内。

执行中或结果未知的关联操作、已提交但结果未确认的注册，会阻止整个删除。
必须先通过已有复核流程确认结果；不将结果未知改写为成功，也不通过删除绕过防重复提交。
依赖变化或锁冲突返回冲突，事务整体回滚。版本冲突不会自动覆盖，需重新核对预览。

## 恢复与备份边界

本功能清理当前数据库和当前浏览器状态，不保证擦除磁盘历史页、WAL、离线备份、
其他管理员浏览器或旺商聊/模型供应商的数据。浏览器重新请求已删除账号时被拒绝。
当前没有已落地的向量库、人物学习库或附件存储，不能将此次清理描述为这些能力已实现。

历史离线备份应按保留周期单独销毁。恢复旧备份前，须从恢复点之后的独立操作记录中
核对 `account_deleted` UUID，并在隔离、禁止原生连接的环境重放删除和业务差异；
不得直接恢复历史会话并上线。删除后新产生的财务及业务记录也须先保全和对账。
当前仅交付此恢复要求，尚未交付自动备份清除或自动重放工具。

## API

- `GET /api/v1/accounts/{id}/removal-preview`：版本、清理数量、保留数量和阻断原因。
- `DELETE /api/v1/accounts/{id}`：JSON `version`、`confirm_name`，校验网站登录、
  超管角色、CSRF、工作台、版本、名称及未知结果；所有数据库变更在同一事务完成。

API 使用组分配事务锁及账号/任务行锁，与开户持久化屏障协调。
大量历史消息的清理时延尚未容量验收；当前同步事务超时会回滚，不回报成功。
当前原生长连接及生产动作仍未验收；该功能不能作为这些链路已通过验收的证明。
后续新增账号所属表、缓存或后台 worker 时，必须扩展清理清单、最终执行校验和回归用例。
