# 手机搜索认证

2026-11-08。旺商聊桌面搜索返回1001的原因仍未确定。本适配依据固定官方
Android 3.7.4 契约补齐手机业务认证，不把1001解释为已证实的客户端限制。

## 范围与流程

管理后台的旺商聊账号工作台提供“手机搜索认证”。仅超管可以配置和认证，
账号必须已有同一原生身份的桌面认证，且属于管理用途。配置导入、查看状态、
开启弹窗均不自动登录或发短信。真实密码、短信及安全验证仍由本人正常完成。
成功后核对手机返回 UID 与既有号池账号；身份不一致时拒绝保存。

独立接口为 `/api/v1/native-mobile-deployment`、
`/api/v1/accounts/{id}/native-mobile-auth` 及其事务、撤销接口。
部署配置和手机会话分别密封，HTTP状态仅返回版本、可用性、采样与安全原因。
网站用户、当前网站会话、账号版本、epoch和配置版本共同约束认证事务。
不保存密码、短信码或官方人机票据，不返回原始供应商正文。

最新产品接入已改为用户添加机器人，按昵称及服务端时间定位传入申请，再做独立
私聊和群内证明；不再调用本手机搜索能力。下述手机精确查找、好友资料和主动申请
保留为超管受控测试底座，须有显式持久授权和一次预算；普通接入旧入口返回410。
手机未认证时拒绝受控搜索，不偷偷回退桌面查询；客户已有好友的私聊证明不受影响。
辣椒聊保留自己的协议和字符串身份。好友关系不等于群归属。

### 搜索与好友资料的身份匹配

Android3.7.4好友资料的account_id是int32，真实陌生人查询可能明确返回默认0。
仅手机路径允许资料账号为0／"0"，且必须先以本人输入的公开账号精确搜索出
唯一目标，再验证资料UID完全一致；继续保留搜索确认的公开账号。缺失、null、
格式错误及非零冲突不能使用此兼容，桌面仍要求公开账号一致。

发送前重新核对搜索、好友关系、目标及手机版本；0绝不作为收件账号。
目标资料冲突、关系不完整和真正作用域变化分别显示，不把默认值误称本人、
机器人或授权变化。此兼容不触发申请、登录、发码或重试，也不替代一次性
本人确认和群归属证明。真实读取、合成发送回归及真实申请验收须分别记录。

## 协议与执行边界

- 配置固定 `protocol_version=3.7.4`、`app_version=337` 和已核对APK的
  appHash；设备3、客户端2、交换版本1703240058617。
- 设备身份与正文摘要按Android契约处理，响应认证和8字节nonce格式不变。
- 与桌面共享既有持久请求编号高水位，重启后不重用编号；不新建计数账本。
- Android用户请求计数另存于手机会话，恢复搜索客户端时按当前账号、epoch和
  两个手机版本原子领取；失败不回退旧计数。它不替代加密nonce高水位。
- 手机会话不能传给桌面恢复器；手机客户端不取得NIM票据，也不承担IM接收、
  群管、资料修改、开户或任意HTTP调用。
- 搜索仍复用账号串行读取、全局两个读取槽和原有上游频控。搜索和发送仅接受
  超管受控测试持久范围；固定目标、一次预算、期限及最终提交栅栏继续检查。
- 准备证据携带手机会话和部署版本。最终提交锁定并复核两版本，撤销、替换、
  账号变化后旧证据失效。结果未知只核对原申请，不能自动重发。
- 替换手机配置或撤销会话遇到未决申请会被阻断；不修改桌面凭据、账号epoch、
  接收开关或接收连接归属。

## Android 登录响应校验修正（2026-11-08）

v79将桌面响应票据的sealed box、时间戳及MAC回显约束错误用于手机登录，
并要求响应手机号完整返回。固定Android3.7.4的`core/user.proto`将响应`token`
标为移动端可忽略；`common/c_phonenumber.proto`允许隐藏号码。请求仍使用
原X-Context、设备3和交换参数，SDK的业务MAC来自签名公钥后16字节，
不是响应中的桌面票据。

手机响应独立核验有效UID、JWT、可搜索账号和安全码状态；账号密码登录核对
请求账号，短信／手机号密码登录允许响应号码省略或脱敏，但完整号码冲突仍拒绝。
加密响应继续核验原请求ID、正文摘要、设备与版本AAD；桌面严格票据校验不变。
固定SDK同时支持HTTPS中的普通JSON响应，该路径由TLS认证来源，不宣称具备
额外的AAD回显证明；不为修复虚构所有成功回包必须加密的契约。生产不信任
自签名证书、不跟随重定向、不使用环境代理，合成TLS用例核验该边界。
保存前仍在现有事务内比较手机UID与已登录管理号池UID，并复核网站会话、
配置、账号版本和epoch。不接受另一个账号，不从响应创建新的号池身份。

无法核验的成功响应进入结果未知，不自动重试，手机会话不保存。新增安全分类
区分身份缺失、账号冲突、手机号格式／冲突和安全状态格式，诊断版本为3；
手机管理器复用原有安全审计。原始正文、响应票据、手机号、密码、短信码、
人机票据及事务句柄均不进入该审计。旧失败响应未保存，不能还原其具体失败分支。
此修正的合成验证、部署和本人真实认证须分别记录。

062为前向迁移，只增加平台角色可读的手机配置和会话表。旧表、061以前的
迁移及旧申请摘要不重写；旧准备记录没有手机版本，不能借新会话继续发送。

## 配置准备

`tools/native_mobile_search_config.py <固定安装包> --output <新文件>`
复用已核验的本地APK读取器生成独立配置，输出文件使用0600权限且拒绝覆盖
或符号链接。执行完全离线，不登录、不请求短信、不发好友申请。
配置只能通过超管弹窗导入，不应提交到仓库、文档、日志或聊天正文。
