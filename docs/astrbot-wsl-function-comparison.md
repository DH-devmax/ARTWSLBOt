## 本轮规则契约

### 关键词回复

```json
{
  "keyword_replies": [
    {"keyword": "营业时间", "reply": "每天09:00开始", "match": "exact"},
    {"keyword": "客服", "reply": "请联系群管理员", "match": "contains", "disabled": true}
  ],
  "feature_options": {
    "keyword_replies": {"enabled": true, "admin_only": false, "cooldown_seconds": 60}
  }
}
```

- 最多100条，关键词最多200字节，回复最多4000字节；字符串必须是有效 UTF-8。
- 空 `match` 与旧记录保持字面包含；`contains` 字面包含，`exact` 整条相等。
  不擅自去空白、折叠大小写或改成正则。
- 按保存顺序选择首个启用规则；不采用远端“完全匹配优先”的排序。
- `disabled` 缺省为 false，保持旧规则可用。旧空回复记录仍可读取，
  其命中仅抑制热群、不发送；编辑器提示补齐内容。
- 冷却是每群共享，缺失或旧值0代表30秒；新设置范围30至86400秒。
  不采用远端逐规则冷却或允许0秒连续回复的行为。
- 候选筛选、入队事务与最终提交均使用同一设置；修改配置提升版本和 epoch，
  原排队工作不能沿用旧设置。
- 完整判定只扫描一次规则，不在判定内部重复调用候选扫描；候选阶段仍保留，
  避免不匹配消息读取原生角色。匹配循环不创建明文缓存或后台任务。

### 拦截词与组合规则

```json
{
  "blocked_words": ["单个拦截词"],
  "blocked_rules": [
    {"name": "组合示例", "words": ["词甲", "词乙"], "disabled": false}
  ]
}
```

单词列表继续采用任一词命中；组合规则要求同一条消息含全部词。
组合最多20条，每条名称最多120字节、2至5个互不重复的非空词，每词最多200字节。
群主、管理员、豁免成员和号池机器人保护不变。优先级仍为拦截词、业务黑名单、
首条关键词回复；处置命中抑制热群，不增加第二次动作。

## 试算与权限

`POST /api/v1/groups/{id}/features/preview` 只检查当前群的已保存配置及当前模块草稿：

```json
{
  "version": 12,
  "feature": "keyword_replies",
  "changes": {"keyword_replies": {"cooldown_seconds": 60}},
  "text": "样本文本",
  "sender": "样本成员",
  "role": "member"
}
```

样本文本最多16384字节；成员为模拟匹配值，角色只接受 `member/admin/owner`。
这些字段不成为原生身份、角色或授权证据。返回固定
`validation_level=simulation`、`applied=false`、`native_submitted=false`，
包含匹配规则、拟执行动作及冷却设置；不写配置、审计正文、任务或原生尝试，
不读取原生名单，也不调用模型。

网站身份、群范围、平台、归属及套餐由服务端校验。只读成员可以试算已保存配置；
带草稿的试算还要求各字段编辑权限和租户上限。禁止跨模块修改、未知字段和过期版本。
交付前再次核验网站会话、群访问和绑定版本。普通保存继续只提交当前模块并使用版本栅栏。

新组合规则和冷却字段默认不开放给助手。已有关键词 `rules` 建议仍按现有权限及模块
开放策略处理，确认摘要显示完全匹配和停用状态；不注册直接保存或发送工具。
旧授权在组合为空、冷却为默认30秒时继续按原有字段执行；使用组合或非默认冷却则
重新检查对应字段权限及租户上限。编辑新增字段始终需要独立授权，不自动扩权。

旧配置兼容和移动端回归分别记录在 [测试报告](test-report.md)。

也不把规则测试记作解码性能或真实原生业务验收。

来源准入、未知结果恢复和独立证据，再决定是否向助手开放。
