# 辣椒聊群通知与原生禁入

核查时间：2026-11-04，Asia/Shanghai。仅使用所有者既有双账号、唯一隔离测试群和固定客户端资料；没有发短信、注册、登录或批量原生操作。

## 契约与实现

固定桌面 1.0.3 的 `App-24552bef.js`：
SHA256 `8b4f4aa542461c7878513b40dadab0896ab9dceadba12d910e61ea6207b32676`。
随包 `@openim-f80223cd.js`：
SHA256 `ea45ea3a94e10e196a4313a17d701a706ed129401464987de6b7d8cf12135f15`。

App 在偏移 1189982 检查踢人、读取禁入和解除禁入三项 SDK 能力；
1190959 调用 `kickGroupMember({groupID,userIDList,reason:"",permanentBan})`。
随包 SDK 在 47749 将该布尔值独立传入原生；48120、48278 分别暴露
`getGroupPermanentBanList` 和 `removeGroupPermanentBan`。
随包 WASM 的 `KickGroupMemberReq` 描述符声明第 5 字段 `permanentBan`；
固定路由为 `/group/get_group_permanent_ban_list` 和
`/group/remove_group_permanent_ban`。这不是根据通用 OpenIM 版本猜测的平台支持。

| 能力 | 具体行为 | 验收边界 |
| --- | --- | --- |
| 普通移出 | `permanentBan=false`，原 `kick_member` 授权 | App 移出已接收；本站本轮没有发出 |
| 移出并永久禁止申请进群 | `permanentBan=true`，独立 `kick_member_ban` 授权 | 适配及合成持久回归；本站真实写入待验收 |
| 原生禁入名单 | 固定单群分页接口，最多 100 页、每页 100 项 | 真实完整空名单通过；非空名单和大列表待验收 |
| 解除原生禁入 | 独立 `remove_group_ban`，先核对完整名单及指定目标 | 适配及合成回归；本站真实解除待验收，不自动邀请 |

原生禁入阻止被移出者再次申请进群，与好友黑名单、项目业务模块的成员黑名单分别管理。
普通踢人授权不能升级为永久禁入；历史授权的动作列表不变。
两种新增动作复用密封持久操作、幂等键、账号和绑定版本、网站操作者、当前原生角色、
截止时间及次数预算。结果未知只查询和核对原操作，不重发。
该功能只加入独立超管受控工具，本轮不向群管助手或热群机器人增加工具。
