# 权限与作用域

| 对象/动作 | 超管 | 租户用户 | 实际放行条件 |
| --- | --- | --- | --- |
| 网站用户、套餐、手动续期 | 管理 | 禁止 | 服务端角色 |
| 账号配置、凭据、全局接入 | 管理 | 仅可见群关联账号的安全状态列 | 凭据列无租户数据库权限 |
| MaiBot 工作台、原生登录、平台人设 | 管理 | 禁止 | 服务端超管角色 + 工作台 + 账号资源范围 |
| 群授权申请 | 审核 | 用一次性码申请 | 不直接产生所有权 |
| 群配置/撤销 | 允许 | 仅自己的群且有对应权限 | 用户权限 + 套餐模块 + 资源归属 + 版本；开启需新鲜原生角色 |
| 群 AI 申请 | 可提交 | 本群、对应权限、有效 AI 套餐及名额 | 仅记录意图；尚未拉群、启用或发言 |
| 活动/财务新增 | 允许 | 仅自己的群且套餐包含模块 | 服务端事务重新读取群归属与套餐 |
| 历史台账/操作证据 | 可读 | 仅自己的群 | RLS；到期不删除历史台账 |
| 受控测试 | 允许 | 禁止 | 标记隔离群、原生管理员、账号开关、作用域、期限、预算 |
| 原生操作、AI 发言 | 当前禁用 | 当前禁用 | 全链路兼容/隔离未验收，返回明确错误 |
| MaiBot 插件、工具、升级、系统接口 | 尚未暴露 | 禁止 | 未完成作用域适配前不能连接租户消息 |

## 数据库边界

- 迁移连接为 `wsl_owner`。运行 API 只持有非超级用户 `wsl_platform` 和受限 `wsl_tenant`。
- 租户查询使用 `SET LOCAL app.tenant_id` 的只读事务；连接池不会保留前一个请求的租户设置。
- `tenant_id` 取自网站会话，不能通过查询字符串、前端提交的租户字段或资源 ID 推导访问权。
- 平台写入路径显式核验所属租户；租户池没有业务表写权限。RLS 是纵深防御，不是跳过应用授权的理由。
- 普通用户看不到全平台账号、其他租户群、共享密钥或原始接入数据。
- `ledger_entries` 对平台运行角色也撤销 UPDATE/DELETE；更正必须新增调整记录，不能覆盖已支付历史。
- 活动成员、账务与操作具有复合租户/群外键，避免平台写入错误作用域。
- 共享 MaiBot 账号不能作为群管账号，反向也不允许；数据库绑定触发器拒绝错池身份。
  旧绑定不静默迁移，若仍指向旺商聊群管账号，新的 AI 启用申请会要求超管人工复核。
- 租户数据库角色不能读取 `personas`、`user_access`、`maibot_settings`，也不能枚举热群账号。

## 工作台与账号

- `X-Workspace: wsl|maibot` 是查看范围，不是授权凭据；不传时为 `wsl`，未知值拒绝。
- 热群机器人入口与 API 均限超管，工作台白名单开放账号、认证、人设、只读聊天群、
  账号级聊天/模型/学习/记忆配置、安全配置日志、能力清单及系统监控；
  用户、套餐、群管、财务、操作与测试接口不能从 MaiBot 工作台调用。
- 账号路径与开户请求体中的账号 ID 必须属于当前工作台。前端切换不修改账号 epoch、会话或连接开关。
- 新账号在统一认证表单中命名并创建；每个工作台独立最多 10 个账号、100 个授权群。
  两池不能重复占用同一个原生身份；聊天授权仍由群管工作台与套餐统一核验。
- 模型密钥加密保存、读取隐藏、留空不覆盖、显式清除；配置草稿不存密钥。
  保存配置返回 `applied=false`，不启动模型或原生动作。
- 原生连接尚未接通；`connection_lifecycle=background` 表示设计契约，不能代替在线证据。

## 用户级权限

参考 `agent-desk` 固定 SHA `9f211c0d799ebc57463d465fc7a34ce39a9e3754` 的权限目录、
角色模板与用户分配方式，适配为当前 SaaS 的后端权限代码，未复制其源码。

- 超管在「用户管理 → 权限」选租户管理员、运营人员、只读用户，或逐项勾选自定义权限。
  管理员包含租户安全权限；运营人员不含财务写入与撤销授权；只读模板仅包含读取。
- `GET /access/catalog` 提供权限目录与模板，`GET/PUT /users/{id}/access` 读取/版本化修改。
  任意自定义角色不能授予平台超管、原生认证、全局配置或 MaiBot 工作台权限。
- 有效权限是用户分配与当前有效套餐的交集，每次请求由后端重新计算。
  历史查询不随套餐到期消失；规则、名单、回复等字段的变更按所属模块单独检查。
- 无显式分配记录的旧用户保留租户管理员模板以兼容既有行为，超管可立即改为只读或自定义；
  普通用户不能自行调整权限，也不能仅伪造 `tenant_id` 或工作台头获得授权。
- 权限更新使用版本号，审计记录生效，并取消该用户尚在排队的操作，不取消其他操作者的任务。
  原生执行器尚未开放，最终提交前的权限重检仍属于原生执行器验收门槛。
- AI 入群/启停申请事务校验归属、有效 AI 模块、租户名额及聊天工作台 100 群上限，使用持久绑定；
  没有验证通过的邀请器/引擎时只保存待处理申请，`ai_enabled` 始终为 false，不创建已执行动作。

## 尚未开放的表面

附件、导出、实时订阅、后台业务任务、原生发送及完整 Go 聊天引擎数据 API 尚未提供。
这些表面必须逐个完成资源归属与混合租户测试后才能开放，不能直接代理旧系统无租户的接口。
部署对外前还需 TLS、MFA/恢复、登录失败告警、密码轮换、运行日志及备份策略验收。
