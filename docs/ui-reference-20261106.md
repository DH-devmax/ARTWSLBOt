# Lumenwave 工作台界面

本轮按所有者指定的“多租户平台接续 · 本地工作区”界面适配，参考其
`AdminShell.vue`、`styles/workspace.scss`、`styles/lumenwave.css`及实际桌面截图。
参考项目位于`/Users/xinxinzi/Developer/多租户系统-vue`，只读使用，没有修改。

## 视觉约定

- 使用 Lumenwave Finance 浅色方案：画布`#eeeff1`，工作面白色，
  主文字`#0b0b0e`，分隔`#e3e5e9`，操作与选中导航`#17171b`。
- 亮黄绿`#d8ff36`只用于选中指示及少量焦点；
  紫色用于数据图表。成功、警告及失败继续使用各自语义色。
- 正文14px，页面标题24px，导航14px；不按视口缩放字体。
  控件圆角6px、弹窗8px，页面区块用分隔线与留白组织。
- 使用本地系统字体、现有 Element Plus 图标和平台图片，不加载模板的远程字体、
  图标 CDN、营销示例、参考项目路由或业务数据。

模板归属、原设计说明和许可证保留在
`web/src/wsl/theme/lumenwave/`，第三方说明同步更新。

## 适配范围

`main.ts`仅加载一套活动主题：`lumenwave/system.css`、
既有结构样式`style.css`及产品适配`theme/product.css`。
旧`--fw-*`变量仅是新主题的兼容别名；Fairweather、Voltline文件不再导入。

公共侧栏224px，折叠后68px；分组支持键盘收起／展开。
移动端继续使用原有导航抽屉，退出移动布局时清理抽屉状态，
折叠提示在移动端禁用，避免隐藏的桌面按钮留下遮挡。
“跳到工作区”只移动焦点，不改变哈希路由。
恢复网站会话后重新同步已获授权的页面哈希，避免监控页刷新回到总览。
保持管理后台／用户中心切换、平台选择、品牌图标及顶部独立助手入口。
不恢复已删除的侧栏同步状态和重复作用域行。

### Logo 与首次接入

后台、用户中心、登录和群管助手统一使用参考项目`AdminBrandMark.vue`的实际三段交叠多边形、
`viewBox="360 380 1320 1240"`及原色顺序，4秒换色并轻微浮动。
不再使用简化三角形、用户头像或旧机器人图标代替品牌。
助手侧栏入口、顶部入口、欢迎界面及回答头像采用同一SVG；
管理后台与用户中心仍以标题、导航和服务端权限区分，品牌图形不表示管理员身份。
系统减少动态效果时停止动画。
群选择入口和候选列表使用所属平台的旺商聊／辣椒聊原图标；
品牌图形表示助手，平台图标表示当前群的来源，切换平台时同步更新。
助手群选择区常驻旺商聊／辣椒聊切换，桌面和手机均可直接选择。
只列出网站会话允许的平台，切换仍停留在助手，取消旧视图和SSE，
重新读取对应平台的授权群与历史。同名跨平台群不共享对话或未发送草稿。
切换、搜索和分页均不创建会话、不调用模型、不改变原生连接。

用户中心工作台首屏固定显示接入指引，不再依赖当前列表为空。
套餐明细、完整费用及权限列表放在“套餐与费用”，工作台保留权益和用量概览。
工作台仅展示最近5条操作，“查看全部”进入完整操作记录；移动端按记录分行展示，
不把历史长表铺在接入指引下方。
1000px及以下按窄工作区展示两列权益和分行群组操作，避免平板保留侧栏后
四列指标与宽表格挤压主要按钮。
负责人点击“接入新群组”打开带当前平台的原有向导；
超管点击“绑定群组”也在用户中心打开接入向导，先选择已有客户作为群的归属，
再分配机器人、在App中邀请、完成群内挑战并本人确认绑定。
客户负责人不显示客户选择，只能接入自己的群。原生管理员申请仍进入审核。
普通成员不显示创建或绑定按钮；未开通、缺权限和平台未包含时显示实际原因。
打开工作台、查看步骤或关闭向导均不创建核验记录。

用户中心没有当前平台授权群时，用统一的接入指引替代空表格：

- 有接入权限且套餐覆盖当前平台的负责人，可点击“接入第一个群组”，
  按准备群聊、邀请机器人、核验绑定三步接入，向导带入当前平台。
- 尚无分配群的成员联系客户负责人；套餐未生效、平台未包含或缺少接入权限
  分别说明原因，不展示可提交接入的入口。
- 超管演示在用户中心选择真实所属客户并完成接入，不要求给超管创建客户或开套餐。
  已绑定群的10分钟测试认领继续独立提供。
- 搜索或客户筛选无结果仅提供清除筛选；加载中与读取失败不显示首次接入引导。

“创建群聊”指在官方App中创建后接入，不新增原生建群能力。
打开和关闭向导不创建核验记录、原生邀请或业务任务；仍需本人点击“开始核验”。

登录表单、顶部工具栏、指标、表格、分页、表单、弹窗、消息列表、
助手历史和对话区统一使用上述视觉语言。业务页使用白色工作面与灰色筛选区，
行操作有明确间隔，导航项40px，普通输入38px；不叠加浮动卡片。
主要操作使用模板的黑色，语义颜色仅表示真实业务状态。
总览、账号与延迟图表沿用现有样本和统计含义，只调整颜色与间距。
助手仍保留最近10轮、唯一空白会话、删除、草稿、单群范围和本人确认。

## 业务与交付边界

v59至v61只修改产品前端及验证、归属文档。v62补充用户中心接入与助手内平台切换，
并增加服务端确认的超管接入模式；客户权益、业务准入、消息结构和`CodecVersion=7`保持原口径。
所有功能编辑继续使用作用域弹窗；浏览页面、切换导航或关闭弹窗不产生提交。
没有新增深色模式、页面业务、后台任务或前端依赖。

v59发布源从实际v58冻结源码提取，Logo与空状态修正以实际v59冻结源码为基线；
v61公共品牌、首屏指引及版式调整以实际运行v60冻结源码为基线。
仅同步对应界面差异，未发布的解码、
媒体及轻量化候选不参与构建。现有Compose只更新Web，API、
热群引擎、数据库及原生接收连接保持原实例。
实测、失败修正和发布证据见`docs/test-report.md`本轮记录；
界面通过不提高`native_ready`或`ai_ready`。
