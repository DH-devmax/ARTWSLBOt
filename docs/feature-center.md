功能管理已按当前管理工作台请求旺商聊或辣椒聊目录；请求、草稿、迟到响应
和保存均包含平台作用域，不再固定为 `wsl`。已有授权群时首次进入页面即加载，
群选择监听先于初始化选群注册，避免首次目录为空。
原生进度复用 ArtDesign Pro 环图，平台支持、代码接入与业务验收分别统计。
业务模块概况分为可见定义、套餐包含、已保存启用与实际链路启用；
草稿开启不能计入保存数，保存数不能计入运行数。
以下早期能力数量和接入描述保留为历史记录，当前目录以服务端返回为准。
导航和助手用户/管理界面设计见 [控制台信息架构](console-information-architecture.md)。

## 入口与真实状态

“功能管理”保留业务模块与原生功能表两个视图；首次默认打开业务模块，
已明确选择原生功能表的账号仍记住该偏好。活动抽奖、财务台账作为业务模块
的管理弹窗，从目录进入并可返回，不再占据平级标签。群组列表配置入口直接打开
指定群的业务模块。
顶部机器人选择继续过滤群范围。群配置弹窗只保留服务总开关、AI 状态和冷却时间。

### 2026-10-31 业务入口归并

活动抽奖与财务台账复用已有目录定义、权限和接口，不重复注册功能或另建存储。
进入管理弹窗传递当前群，记录列表按该群过滤，新建表单预填同一群；改变群后返回
目录沿用该选择。筛选按平台、网站用户、租户及账号隔离；切换账号不会带入
另一个账号的筛选。列表补充群列，未筛选时可区分记录归属。
这里筛选的是接口最近最多200条可见记录，不是服务端群级全量历史查询。

仅具 `ledger:read` 或 `activities:read` 的成员可进入权限内的精简业务目录，
不请求需 `groups:read` 的原生/群配置接口；旧 `#ledger`、`#activities` 深链接
继续校验权限。没有群目录时，群选项仅来自已获授权的业务投影，
名称缺失显示原群编号，不补发权限或猜测群归属。
两项业务仍限现有WSL工作台，不因前端归类扩展到辣椒聊。
目录切换、返回、筛选和打开新建表单不写业务数据。
没有添加通用启用开关、自动转账、群内报名或自动结果发布。

### 弹窗编辑基准（2026-10-31）

目录只展示已保存状态，不在表格中放启用开关或全局保存按钮。每个可配置模块
通过详情弹窗编辑，底部保存只提交该模块变化及群配置版本，不能顺带保存其他模块
草稿。返回保留当前作用域草稿，放弃修改只清除当前模块输入；平台、网站用户、
租户、账号、群之间继续隔离，版本冲突必须核对后重试，迟到响应不得清掉新草稿。
保存不等于运行启用，未迁移能力不生成占位编辑控件。

财务台账、活动抽奖在管理弹窗中展示和筛选，创建及开奖仍使用各自表单或确认弹窗，
并保留原权限、幂等和人工确认契约。旧深链接打开同一管理弹窗。列表和管理弹窗
共用既有授权投影；打开、关闭和筛选不写数据。弹窗复用产品主题与响应式
最大宽高、滚动正文、可见底部操作。

“仅群管理员触发”限定未来已核验的原生发言者角色，不授予网站用户管理员权限。

## 代码与存储

- `internal/features/native.go` 是原生基础能力及支持证据、接入状态的来源；
  `Definition.native_dependencies` 声明各业务模块的原生依赖。
  接口返回 `native_capabilities`；群模块另外返回 `native_blockers`。
  未知或尚未验收的依赖默认阻断目录就绪判断。它不是原生执行器，
  不能替代控制面提交时的权限、角色、期限及 epoch 校验。
- `internal/features/catalog.go` 是功能 ID、分类、字段类型、限制及校验的来源，
  不依赖 HTTP、数据库或原生传输。
- `internal/httpapi/features.go` 负责租户、授权、套餐、字段权限、事务和版本栅栏。
- `web/src/wsl/FeatureCenter.vue` 负责业务配置及作用域草稿；
  `NativeCapabilities.vue` 展示只读原生能力表及证据详情。
  模块依赖项可以直接打开对应原生能力详情，不复制上游页面。
- 保留原有 `group_bindings.config` 的词、名单、回复字段；新增
  `feature_options[功能 ID]` 保存独立开关。未新增表或修改已应用迁移。
- 配置写入提升群 version/epoch，取消该群排队操作；不修改接收器、账号会话或连接。
  删除机器人原有群配置清理路径也会清除 feature_options。
- 旧群配置 API 保留 feature_options；不能经该 API 修改这些开关。原有宽权限保留兼容。

扩展功能需增加目录、类型化读写/限制、字段权限与测试；真实执行能力必须独立完成
消费器和最终权限栅栏验收，不能因新增目录项就开放。

## 原生功能表的含义

### 2026-11-01 目录拆分与同步

[生成目录](feature-catalog.md)是当前完整产品范围、两平台差异和业务依赖快照，
由`internal/features`生成，不手工维护数量。原生目录补列授予/撤销管理员、
语音/文件接收、私信图片与辣椒聊注册；辣椒聊尚未适配的其他能力明确显示待接入、
待核验，不从旺商聊继承协议支持、角色许可或受控通过。
账号设置、媒体发送、入群邀请/接受、本人/他人群昵称、全群禁言/解除、
好友同意/拒绝和注册短信/提交拆成独立只读子项。

接口的可选`native_details`携带父能力组ID及独立状态/证据；旧ID、业务依赖、
配置字段、授权和控制执行语义不变。默认表格按独立验收项展示，依赖链接仍可打开
能力组及其子项。能力组历史受控数与独立完整验收数分别统计；
他人名片和其他平台不会继承本人测试结果。原生表和详情标明“原生底座”，
业务表及只读详情标明“业务模块”；人工好友审批与自动审批模块等分别验收。
无配置字段的业务模块也可只读查看状态与依赖，不生成启用/保存控件。

新增能力、子项、业务定义或验收记录时，运行
`go run ./tools/feature_catalog -write`同步文档；
`go test ./tools/feature_catalog`及CI的`-check`拒绝陈旧目录。
历史报告数量仍保留原采样时间，不能用新目录数量改写过去验收结果。

目录核对基线为旧接入器 `a672ef9` 与固定官方客户端证据，当前接入仅桌面2.8.3；
早期Android结构证据不作为桌面执行许可，也不是官网最新完整功能的声明。
已登记的基础能力包含认证、消息、群目录、
成员映射、角色、禁言/解禁、撤回、公告、名片、好友读取和邀请记录。
好友审批、邀请入群/本人接受/退群已接入固定桌面提交契约、持久授权及最终栅栏。
2026-11-01 大蛤在唯一测试群接受现有邀请后通过双侧完整成员核验；好友审批与
更广恢复组合仍待验收，完整边界见 `native-social.md`，不据此提升全局 readiness。
图片、语音、视频及文件已有有界上传/发送底座；真实完整收发仍未验收。
语音/文件接收仅有元数据，不能用上传成功或发送侧实现代替接收验收。

支持状态、本项目代码接入状态、当前账号连接状态及整体验收是不同概念。
原生功能表不提供开关或直接执行按钮，不因打开详情发出原生请求。
已实现认证不等于完整验收；部分实现接收不等于真实在线；生产业务完整验收数仍为零，
受控场景通过记录按上述独立口径展示。
实际角色限制必须以原生最新响应为准；表内权限是待验证的调用约束，不是授予权限。

业务模块声明基础依赖，例如关键词回复依赖收消息、角色核验、发文本；
名片依赖成员列表、角色及原生改名片。引用回复、@ 和禁言不再作为售卖模块或字段，
后续按具体模块策略调用统一控制能力。财务台账的 Web 操作没有原生动作依赖，
活动 Web 创建/开奖不被待迁移的群内报名/发送依赖阻断；两种状态同时可见。
本次仅建立目录及依赖契约，未新增原生发送或群管执行链路。

## 接口和字段分权

- `GET /api/v1/features/catalog`：功能目录，需群读取权限。
- `GET /api/v1/groups/{id}/features`：当前群配置、版本及可编辑字段。
- `PUT /api/v1/groups/{id}/features`：`{version,changes:{功能 ID:{字段:值}}}`，
  多字段原子保存；未知功能、未知字段、错误类型及超限拒绝。
- `feature:<功能 ID>:<字段>` 为单独字段权限，自动进入用户权限目录与角色模板。
  例如 `feature:keyword_replies:enabled` 不授权修改 `admin_only` 或 `rules`。
- 原有 `groups:replies` / `groups:moderation` 仍为对应功能的宽权限。
  需要严格字段分权的自定义用户不应同时获得这些宽权限。
- 服务端重新核对资源租户、有效群授权、机器人未删除、有效套餐及模块。
  超管仍不能绕过套餐和版本要求，也不能在热群工作台调用本接口。
- 草稿按网站用户、租户、账号和群隔离；失败/冲突不清空输入，
  新版本需要显式核对后采用，迟到响应不覆盖另一个账号。
- 审计只记录变更的功能/字段名、版本和未执行标志，不写回复正文或成员名单。
