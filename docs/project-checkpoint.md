## 当前架构与业务

| 范围 | 实现与所有权 |
| --- | --- |
| 产品 UI | `web/src/wsl`，Vue / Art Design Pro / Element Plus；用户中心、两平台群管、超管热群控制台 |
| 身份与控制 | `internal/httpapi` / `internal/control`；网站认证、账号池、租户群授权、套餐、版本栅栏、持久操作及审批 |
| 原生接入 | `internal/nativeauth` / `internal/nativewire` / `internal/lajiaoliao` / `internal/gateway`；每个原生身份一个连接所有者 |
| 接收热路径 | 有界接收、密封持久化、提交后 ACK；解码、投影、SSE、目录读取与 AI 均不阻塞 ACK |
| 读取调度 | 账号串行、全局有界；缓存、合并与限流由 gateway 管理，关键动作仍需新鲜权限证据 |
| 群管业务 | `internal/features` 定义能力与配置；保存配置不启动规则消费器或原生执行 |
| 受控 Tools | 超管人工创建隔离授权，限定账号、群、目标、动作、期限与预算；未知结果只查询与对账 |
| 群管助手 | `internal/assistant` 为有界编排；Eino v0.9.22 仅在 adapter；模型只建议，人工审批通过共享控制事务 |
| 热群 AI | Go `internal/heatbot`，只生成文本提案；无原生发送、数据库、财务、主机或插件执行权 |
| 共享 AI 网关 | control 管理密封业务密钥、版本费率、单次热群凭证及积分预留；未知用量保留占用，不自动付费重试 |
| 数据与监控 | PostgreSQL 强制 RLS；受限租户事务设置网站 actor；Simon 私有且无主机根目录或 Docker socket |
| 交付 | 仅现有 Docker Compose，保留 release/development 模式、本地限额及前一运行版本 |

管理与热群用途各共享 10 个跨平台账号，每号最多 30 个绑定；
管理群总计最多 300 个，热群只覆盖相同已授权群。切换工作台只改变视图。
PLUS 为 29 USDT / 720 小时、1 群 3 人；PRO 为 49 USDT / 720 小时、
3 群 10 人，每期 10,000 积分由两种 AI 共享。提前续期不提前发积分，
旧 Token 余额不转换，非主账号仍需显式群授权。

辣椒聊使用官方桌面短信注册或登录流程：先人工验证并发送短信，再明确确认。
手机号密封绑定网站用户、会话、账号与设备；OTP 和滑块结果不持久化。
保存原生会话后仍需单独开启接收。旺商聊继续使用桌面 2.8.3 契约。
