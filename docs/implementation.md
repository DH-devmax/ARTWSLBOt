## 不能启用的能力

- `ENABLE_NATIVE=true` 时 Go 服务拒绝启动；API 不允许打开原生账号接入。专用原生认证 API 可由超管主动提交登录，认证成功也不会打开消息连接。
- 原生开户须先导入受控部署配置；缺配置时不显示凭据表单、不发开户请求。顶部统一表单先填写机器人名称，首次有效提交创建面板；注册成功不等于登录或连接。
- `/api/v1/operations` 返回 `native_compatibility_not_verified`；不会把未发送动作记录为成功。
- 直接启用群 AI 仍返回 `ai_isolation_not_verified`；独立申请接口只保存待验收意图，返回 `enabled=false,executed=false`；`healthz` 和前端明确显示两个未验收状态。
- 历史 Python 桥接不部署；Go 引擎健康返回 `parity_verified=false`，生产容器禁用测试生成。
  没有空作用域回退或未经适配的 Python 插件处理租户消息。
- Go 模型调用当前只含文本提供器，视觉/向量/学习等未来路径必须经过同一全局调用上限。
- 尚无生产原生连接所有权/恢复水位/权限最终提交栅栏的端到端证明，不能只凭纯函数/队列测试宣称完成。
